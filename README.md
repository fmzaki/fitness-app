# 🏋️‍♂️ Fitness Tracker - Full Stack Application

A complete workout tracking system with user authentication, exercise logging, and progress analytics.



## ✨ Features

- **User Authentication** (Register/Login with JWT)
- **Workout Management**:
  - Create workouts with multiple exercises
  - Track sets, reps, and weights
- **Dashboard Analytics**:
  - Workout type distribution (Bar chart)
  - Training volume trends (Line chart)
  - Personal records tracking
- **Responsive Design** (Mobile & Desktop)

## 🛠 Tech Stack

**Frontend**:
- React.js
- Chart.js (Data visualization)
- Tailwind CSS (Styling)
- Axios (API calls)

**Backend**:
- Node.js + Express
- MySQL (Database)
- JWT (Authentication)

## 🚀 Getting Started

### Prerequisites
- Node.js (v16+)
- MySQL (v8.0+)
- Git
